# MyHunter

> **2D Arcade Shooting Game in C with CSFML.**

## Overview
Classic Duck Hunt arcade game developed using the CSFML multimedia library:
- Animated target sprites traversing the screen with variable trajectory and velocity
- Custom crosshair cursor tracking mouse input and gunshot hit detection
- Wave progression system with increasing difficulty, scoring, and lives

## Build & Usage
```bash
make
./my_hunter
```
